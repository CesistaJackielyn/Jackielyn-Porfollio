Main Features

  • Product Browsing
  • Product Search
  • Product Categories
  • User Profile
  • User Registration and Login

Technologies Used

Wumpus World

Wumpus World is an interactive AI-based game where the player explores a cave, finds gold, and avoids dangerous areas such as pits and the Wumpus. It helps users understand how artificial intelligence uses reasoning and decision-making in a game environment.

Main Features

  • Interactive Cave Exploration
  • Player Movement and Navigation
  • Gold Collection and Game Scoring
  • Shooting Arrow Mechanic
  • Auto-Play and Reset Game
  • Game Status Monitoring

Technologies Used

HTML CSS JavaScript

What I Learned

I learned how artificial intelligence can be applied in games and how logical reasoning helps in making decisions. I also learned about game mechanics, player movement, and how to create an interactive web-based game.

View Project

StockTrack

A mobile inventory app where staff manage supermarket products in real time and guest buyers can check prices and stock before visiting the store. It syncs with the cloud and still works offline.

Main Features

  • Staff login with full CRUD on products (add, edit, delete)
  • Search bar
  • Offline cached inventory and push alerts for low or out-of-stock items

Technologies Used

JavaScript Firebase

What I Learned

I learned how to build a cloud-synced mobile app with Firebase, including role-based access, real-time updates, and offline caching with AsyncStorage. I also practiced designing clear loading, empty, and error states, and testing the app thoroughly with 30 test cases.
